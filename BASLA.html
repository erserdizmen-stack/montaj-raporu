📋 Montaj Raporu Formu

İnternet'e koyma - 3 adım, 2 dakika

✅ Form hazır! Şimdi internete koymak için 3 tıkla işi bitireceğiz.

1️⃣ ADIM: GitHub'da Repository Oluştur

Git Hub'a git (yeni sekmede aç):

github.com/new

Sonra:

• Repository name yazan yere yazılanı yazınız: montaj-raporu

• Public seçili mi kontrol et (böyle kalmalı)

• Aşağıda yeşil "Create repository" tuşuna tıkla

2️⃣ ADIM: Dosyaları Yükle

Repository açıldı. Artık:

• Yeşil "Code" tuşunun yanında "Add file" tuşu var

• Add file → Upload files tıkla

• Bu sayfada index.html dosyasını sürükleyip bırak

• Yeşil "Commit changes" tuşuna tıkla

3️⃣ ADIM: GitHub Pages Aç

Repository'nin Settings kısmına git:

• Üstte Settings tab'ı tıkla

• Sol menüden Pages tıkla

• Source kısmında Deploy from a branch seçili

• Branch olarak main seç

• Save tuşuna tıkla

🎉 Bitti! Sağ üstte linki göreceksin:

https://[senin-github-adın].github.io/montaj-raporu/

💡 Not: Link 2-3 dakika sonra çalışmaya başlar. Hemen çalışmazsa, 5 dakika bekle ve yenile.
